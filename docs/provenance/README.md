# DX Artifacts provenance

## Purpose

DX Artifacts records the external lineage of the implementation and evidence used to bootstrap this new repository. Provenance explains origin; it does not transfer continuing product ownership to a source repository and does not establish conformance by assertion.

- [Implementation lineage](implementation-lineage.md) identifies the source implementations and evidence.
- [Repository and package boundaries](../architecture/repository-and-package-boundaries.md) defines native product ownership and future consumer boundaries.
- [Bootstrap baseline](../migration/bootstrap-baseline.md) defines how DX Artifacts accepts a controlling implementation baseline.

Provenance does not change carrier grammar, envelope grammar, or CLI behavior.
